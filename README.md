# Bell-states-on-qiskit
This repository provides a clean and modular implementation of Bell state generation and measurement using Qiskit, IBM’s open-source quantum computing framework. Bell states represent the simplest and most fundamental examples of quantum entanglement, forming the basis for quantum teleportation, superdense coding, and many quantum communication protocols.

The notebooks and scripts included here demonstrate:

Construction of all four maximally entangled Bell states

∣Φ+⟩,∣Φ−⟩,∣Ψ+⟩,∣Ψ−⟩

Use of Hadamard (H) and CNOT gates to engineer entanglement

Simulation of quantum circuits on Qiskit’s statevector and qasm backends

Measurement, probability distribution analysis, and histogram visualisation

Execution on real IBM Quantum hardware (optional, via user credentials)

The repository is designed to be both educational and practical:

Beginners gain a step-by-step understanding of entanglement circuitry

Researchers and students can extend the circuits for larger algorithms

Educators can embed the examples into labs or tutorials

Whether you're exploring entanglement for the first time or integrating Bell pairs into more advanced protocols, this codebase offers a solid starting point built on industry-standard tooling.
